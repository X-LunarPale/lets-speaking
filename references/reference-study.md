# 《第二章》说话调教参考研究

参考：`第二章.acep`，2026-11-08 离线读取。原文件没有改写；实时 ACE 工程出现未保存内容，因此没有强制切换，也没有合成或试听。以下是数值研究，不是听感验收。

## 数据规模和正确的样本边界

| 项目 | 实测 |
|---|---:|
| 工程轨道槽 / 有内容轨道 | 100 / 5 |
| 片段 | 96，95 个含音符的人声片段及 1 个空人声片段 |
| 全部存储音符出现次数 | 53,528 |
| 可见音符出现次数 | 4,601 |
| 可见不同音符 UUID | 4,552 |
| 可见语言 | CHN 4,598；ENG 3 |
| 存储音高曲线 | 2,376，全部 `type:data` |
| 与可见范围相交的曲线 | 364 |
| 可见音高采样数 | 1,047,526 |

95 个含音符片段复用了若干完整源数据，再分别裁切。排除空片段，按完整音高数据去重后有52组；按完整音符及参数内容则有59组。没有音频轨，另1个片段 T4/P0 是空人声片段。不能用存储总数声称有五万多个独立训练样本；也不能删除隐藏源数据来“清理工程”。

## 说话节奏

可见音符时长 tick：P05=42、P25=110、中位=150、P75=183、P95=240；最短15，最长414。多数时间120 BPM，中位约156ms。569个音符是 `-` 延续标记；追溯头部后有4,032组发音编码单元，合并时长中位169.792ms。不能直接把音符数和时长称为字数、字长。

只有 239/4,601 个起点落在 30 tick 网格上。片段内至少四分之三的相邻音符无间隔，另有较长句间停顿。该工程通过不规则字长和停连塑造语流，不应套用歌曲节拍量化。

音符支架 MIDI 40..69，中位 59，各轨中位 59、59、61、58、58。这不是实际手绘 F0，也不是允许音域边界。

## 音高形态

原始偏移包含大量 `-53/-57/-63` 等平台；184,759个可见采样精确抵消最近音符支架，且全部缺少序列化VUV值。这与零音高类表示相符，但不证明引擎有效清浊。整个偏移分布 min=-67、median=-0.884594、max=23.705053。对该混合分布设置全局均值、标准差阈值，不能作为修复规则。

以下示例在相对稳定的单音符内部观察 `note.pitch + delta` 的近似变化，仅用于说明参考的快速转折。位置均为 **0 基轨道、0 基原始片段、局部 tick**；原始片段索引不直接等于 CLI 排序索引。

| 定位 | 字音 | 五个顺序采样的近似 MIDI |
|---|---|---|
| T0/P0，音符起点2922，支架63 | yang | 63.344, 63.573, 63.612, 63.470, 63.079 |
| T0/P0，音符起点17139，支架60 | su | 58.710, 57.564, 55.341, 54.994, 57.435 |
| T0/P0，音符起点17821，支架53 | zao | 53.561, 52.584, 52.340, 52.439, 54.676 |
| T4/P1，21666..21759 | geng | 64.496, 63.498, 62.499, 60.421, 55.282 |
| T1/P2，71281..71334 | de | 54.634, 57.939, 61.468, 62.409, 63.400 |

可见快速下落、上扬、凹陷和回升。快速移动数个半音本身不是损坏；全局拉直会破坏此参考的说话方式。不能仅凭未标调的 `yang/su/de` 断言具体汉字或词调。

`assets/reference-contours.json` 保存40个可定位的逐tick **相对偏移**示例，涵盖rise/fall/peak/valley/turns/level。更新后的去重比较实际曲线、范围及发音，保留同UUID的不同轮廓；分类只描述原始曲线几何，不是普通话声调类别。用于定位和比较，不能直接写入绝对音高CLI，不能因为入库就认定健康。

## 参数

以下样本数都限制到片段可见范围；曲线条数为全部存储。分位数使用线性插值。

| 原始参数 | 存储曲线 | 可见采样 | 实测范围 / 中位 |
|---|---:|---:|---|
| energy | 643 | 34,214 | 0.677419..1.440860 / 0.967742 |
| vuv | 942 | 10,808 | 0 共1,937；1 共8,871；时序支持0清/1浊，非原生有效清浊 |
| breathiness | 3 | 730 | 0.731183..0.996595 / 0.931900 |
| gender | 1 | 500 | 0.001971..0.068100 / 0.039427 |

`tension/falsetto/realTension/realFalsetto/realBreathiness` 在参考中是存在但为空的层，不是损坏。

仅 T1/P0 和 T1/P1 有 vocal controls：

- T1/P0：soft 29 点，约0.094477..0.243180；power 1 点，-0.109012。
- T1/P1：soft 613 点，约-0.063730..0.153150。
- 对应 global 均0。

因此不要给 `realEnergy/soft/power` 套一个通用非负范围，也不要把旧式 energy 倍率照抄到另一声源的新式参数层。音高修复通常保留这些参数即可。

## 发音和声源

3,897个可见头辅音时长值，范围约0.01161..0.24381秒，中位0.06966秒。头辅音在音符起点之前，469个原始长度超过音符时长不能直接判坏；当前引擎还会根据相邻发音约束有效长度，原始时长也不证明人工编辑。

185个可见音符的 `syllable` 不同于 `freezedDefaultSyllable`，其中183个只是空当前值，使用冻结默认发音；只有2个是非空显式不同值，不能称为185次人工改音。135个音符有正 `brLen`，均在同轨至少250ms间隔之后，但多数此类间隔没有换气标记。修复音高应保留这些存储意图。

没有单独序列化的 note vibrato 字段，但不能据此推断最终输出无颤音或细小起伏。声源名字为空，数字配置显示轨1与其余轨不同；不推断具体声库名字，不把不同轨统一成一个音域。

## 参考自身的疑点

用户指定的风格参考不等于每个采样都已被试听证明正常：

- T4/P6，局部91551..91554附近，有 `-57 -> +19.4 -> -57` 的极短变化。它位于1085 tick音符间隙，四个突变采样恰好都有原始 `vuv=0`；不能据此认定可闻损坏。11份曲线副本相同。
- T0/P10，局部55488偏移达+23.705，位于可见 `wei` 音符内部；附近没有原始VUV或energy覆盖。20份曲线副本相同，不能从另一相同副本获得健康原版。

两者可能是无声区残留、编码/清浊边缘、真实毛刺或有意数据；离线不能定论。它们不能进入自动“正确轮廓”模板，也不能据此修改参考。先看实际 `voicing`、渲染覆盖及声音，再定性。

## 可复用结论

此用户的说话风格依赖连续而非音阶化的音高、音节内部转折、不规则时序和少量局部能量调节。修复应优先恢复被破坏的局部结构，保留原有峰谷、上扬、下落与停顿。单个音域或斜率阈值只能产生待检查候选，不能直接自动改值。

第二轮的实际tempo、清浊对齐、不同版本、插值损失和可检索索引见 [deep-study.md](deep-study.md)。其中纠正了第一轮将空人声片段归为音频片段，以及将原始发音字段不等误作人工修改证据的解释。

后续独立审查还修正了发音检索、旧轮廓去重与默认简化，并量化数值候选的证据边界，见 [repair-validation.md](repair-validation.md)。
